# ✂️ Barbearia Agendamento

Sistema de agendamento online para barbearias e outros tipos de serviços.  
Desenvolvido com **HTML, CSS e JavaScript**, focado em responsividade e simplicidade.  

Na versão inicial, o cliente seleciona o serviço e horário desejado e, ao confirmar, é redirecionado para o **WhatsApp** com uma mensagem automática já preenchida.  
Futuramente, o projeto terá login, armazenamento de agendamentos e painel administrativo.

---

## 🚀 Funcionalidades

### Implementadas
- Estrutura inicial com HTML, CSS e JS
- Páginas de serviços, agendamento e contato
- Layout responsivo
- Redirecionamento para WhatsApp com mensagem automática

### Futuras
- Integração com banco de dados
- Login de clientes e profissionais
- Notificações de agendamento
- Painel administrativo para controle de horários

---

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- WhatsApp API (via link `wa.me`)
